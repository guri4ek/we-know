## Правила продовження

Цей чат — початкова оркестрація проєкту. Документація зберігає контекст для наступних задач, але план не є дозволом реалізувати весь MVP одразу. Поточний обсяг: мінімальний skeleton і документація. Наступний логічний крок — перевірка Jev та редакторська таксономія.

Розрізняти **рішення користувача**, **архітектурні пропозиції** та **факти перевіреної реалізації**. C4 показує цільову MVP-архітектуру, а не вже написаний код. Оновлювати статус документів разом зі зміною реалізації.
